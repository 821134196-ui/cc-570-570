# 门店商品价保申请与差价退款系统

顾客发现活动降价后在订单中申请价保，店员复核规则并退款。差价按**原订单实付、已使用优惠、当前有效价格**计算，申请页逐项展示计算依据；全程幂等防重，多次降价只退新增差价。

## 一键启动

```bash
./start.sh
```

打开 http://localhost:3000 （后端 Axum 直接托管前端构建产物；SQLite 自动建表并写入演示数据，库文件在 `backend/data/app.db`）。

依赖：Rust（cargo）、Node.js（npm）。首次运行会自动下载依赖并编译。

## 技术栈

- **后端** Rust + Axum + SQLx（SQLite），金额一律用整数“分”
- **前端** Svelte + Vite（构建为静态文件由后端托管）
- **价格接口 / 支付网关** 本地模拟：价格事件流水表 + 独立网关台账表，回执经 webhook 入账

## 业务规则实现

| 要求 | 实现 |
|---|---|
| 差价计算 | `总差价 = 原实付 − 当前应付`；`当前应付 = 当前活动价×数量 − 当前规则优惠`（`backend/src/calc.rs`） |
| 券不重复抵扣 | 当前应付计算中**不再**扣原单已用活动券（券已体现在原实付里） |
| 多次降价 | `本次应退 = clamp(总差价 − 已退差价, 0, 可退上限)`，只退新增部分 |
| 累计上限 | 可退上限 = 原实付 − 已退；复核时在事务内重算并再次钳制 |
| 逐项计算依据 | 预览/申请接口返回完整 Breakdown（原价、券、两个规则版本、已退、本次应退）+ 逐项资格检查 |
| 拒绝原因 | 规格不符（同商品不同 SKU）/ 已退货 / 超价保期 / 无差价 / 无新增差价，逐条给出 |
| 重复申请 | `Idempotency-Key` 唯一约束 + 同明细待审核申请复用 |
| 回执重复送达 | `payment_receipts.receipt_no` 唯一 + 退款状态条件更新（initiated→succeeded） |
| 支付网关幂等 | 网关台账 `idempotency_key` 唯一，重复调用返回同一回执 |
| 数据不可变 | 订单/退款只插不改；申请、退款状态机单向流转；规则版本与计算快照永久保留 |

## 演示流程

1. **演示控制台** 依次点击预置降价 ①②③（耳机标准版 ¥500→¥450→¥400→¥380，规则版本 v1→v2→v3）
2. **顾客页** 订单 O1004（无券）每次降价后点「申请价保」→「店员页」复核通过：
   - ①后：退 ¥50.00（50000−45000）
   - ②后：当前应付 40000−3000（满减）=37000，总差价 ¥130，已退 ¥50，**本次只退新增 ¥80**
   - ③后：38000×0.9=34200，总差价 ¥158，已退 ¥130，**本次退 ¥28**
3. **券不重复抵扣**：订单 O1001 实付 ¥450（活动价 ¥500 − 券 ¥50）。降价①后当前应付 ¥450，差价为 0 —— 系统不会把 ¥50 券再算一次
4. **重复申请**：顾客页「重复提交」按钮用同一幂等键再提交 → 返回原申请，不重复建单
5. **回执重复送达**：店员页退款记录点「重放回执」→ 提示“重复送达，已忽略”，退款金额不变
6. **拒绝场景**：O1002 已退货、O1003 已超价保期、O1001 点「按Pro版降价申请」（规格不符）→ 均给出明确拒绝原因
7. **规则版本对比**：每次申请快照固化当时规则版本，申请记录里可看到 v1/v2/v3 下的不同计算结果

## API 一览

```
GET  /api/orders?customer=            订单列表（含明细、已退金额）
GET  /api/price-protection/preview    价保计算预览（逐项依据+资格检查）
POST /api/applications                提交申请（需 Idempotency-Key 头）
GET  /api/applications?customer=      我的申请
GET  /api/staff/applications?status=  店员复核队列
POST /api/staff/applications/{id}/approve  复核通过并退款（事务内重算）
POST /api/staff/applications/{id}/reject   拒绝
GET  /api/staff/refunds               退款台账
POST /api/webhooks/payment            支付回执 webhook（幂等）
GET  /api/meta                        规则版本/SKU/价格事件
POST /api/demo/price-drop             模拟降价
POST /api/demo/receipts/{no}/resend   模拟回执重复送达
POST /api/demo/reset                  重置演示数据
GET  /api/mock-pay/refunds            支付网关台账
```
